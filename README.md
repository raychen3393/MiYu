# 密语 MiYu 3.0 · 局域网加密聊天与 2.5D 潮玩萌宠

同一个局域网里就能聊天，**不需要服务器、不需要手机号、不连外网**。支持公开大厅、私聊、暗号群，所有传输端到端加密。内置 **2.5D 黏土盲盒宠物引擎**、派对游戏厅、无边框通顶毛玻璃界面与语法高亮代码块。可以记住登录（下次自动进入），聊天记录默认不保存。

---

## 一、怎么运行

### 方式 A：打包成 exe（推荐，用来发给别人）

1. 电脑上装好 Python 3.10 或更新版本（https://www.python.org/downloads/ ，安装时勾选 **Add python.exe to PATH**）
2. 双击 **`build.bat`**，等 3～8 分钟
3. 得到 `dist\MiYu.exe`，把这一个文件发给同一局域网的人，双击就能用，**对方不需要装 Python**

### 方式 B：直接运行源码

双击 **`run.bat`**。第一次会自动准备环境（需要联网，1～3 分钟），以后双击就直接打开。

### ⚠️ 第一次打开时的防火墙提示

Windows 会弹出「Windows 安全中心警报 / 防火墙已阻止此应用的部分功能」，请勾选 **专用网络**（如果你的网络被设成了"公用"，两个都勾），然后点 **允许访问**。
不允许的话，别人发现不了你，你也连不上别人。

如果当时点了取消：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到 MiYu（或 Python）勾上。

| **五子棋大厅（2.2）** | 左上角的 **棋盘按钮**（或输入框旁 ＋ →「五子棋大厅」、右键成员 →「邀请下五子棋」）打开独立的五子棋窗口，上面四页：**大厅 / 对局 / 排行榜 / 我的战绩**。大厅里可以 **创建房间**（房间名、每步限时 30 秒 / 60 秒 / 2 分钟 / 不限时、执黑 / 执白 / 随机），在线的人都能在「房间列表」里看到并一键加入；也可以在右边「在线好友」里直接 **邀请** 某个人，对方会弹出邀请窗口，30 秒内接受或拒绝；还能和电脑 **人机练习**（简单 / 普通 / 困难，不计分） |
| **联网对战** | 标准 15×15 棋盘，黑棋先手，横竖斜任意方向连成五子（或更多）获胜，下满没人赢算平局。两边实时同步落子、轮到谁、头像昵称、在线状态、每步倒计时（头像外面一圈，时间越少颜色越暖）和累计用时；时间到了算输。落子有缩放淡入的动画，最后一手中间有个小点，轮到你时鼠标处有半透明的预览棋子；赢了五子连线发光，结算卡片上积分往上跳、显示名次变化，还会撒彩带。可以 **悔棋**（要对方同意，轮到你时退两手，刚下完退一手）、**重新开始**（要对方同意，这盘作废）、**认输**、**退出对局**（未结束时算认输）、**再来一局**（交换先后手）。网络断了双方计时都暂停，重新连上自动同步接着下；对方掉线超过 90 秒可以判对方负，等对方的软件回来确认后才计分 |
| **积分排行榜** | 每盘结束自动结算：**胜 3 分、平 1 分、负 0 分**，累计总场次、胜 / 负 / 平、胜率、当前连胜和最高连胜。排行榜分 **总榜 / 今日 / 本周**（今日 = 本机时间今天 0 点起，本周 = 本周一 0 点起；总积分永久保留），按积分从高到低，同分比胜场，再比胜率，完全一样的并列。自己那一行高亮，底下一条告诉你排第几、离上一名还差几分。**我的战绩** 里有六个数据卡片和每一盘的对手、结果、得分、时间、手数，可以筛选对战 / 人机练习，点「复盘」一步一步回看（棋子上标着第几手） |
| **排行榜防作弊** | 没有服务器，排行榜是每台电脑从同一批对局记录算出来的：对局结束后记录发给所有在线的人，有人上线时双方自动对一下缺哪盘补哪盘，所以大家看到的榜一样。**每一步都由下这一步的人用自己的身份私钥签名**，并且串成一条链，别人改一步、删一步、调换顺序都会被发现；连成五子由棋谱本身证明，认输和超时由输的一方签名，掉线判负要输家的软件确认（对方明明在线却被判掉线，他的软件不会确认，这局就不计分）。所以谁也没法凭空给自己记一场胜利，同一盘棋提交多少次都只算一次。**防刷分**：同一对玩家 24 小时内最多 5 局计分；认输 / 超时 / 掉线结束的，不到 10 手不计分；结束时间比现在晚的先不算 |

## 三、安全设计

- **身份**：第一次启动随机生成 Ed25519 密钥，昵称随便起，不绑定任何真实信息。开了「记住登录」时私钥加密保存在本机；没开的话只在内存里，关掉软件就永久消失
- **发现广播**：每 3 秒在局域网里广播一次，内容加密并签名，所有广播包长度相同（540 字节）。
  - 暗号群的广播用暗号派生的密钥（scrypt）加密：不知道暗号的人只能看到随机数据，看不出有这个群，也看不出谁在群里
  - 公开大厅的广播密钥是公开的（任何装了软件的人都能进大厅），只起防止明文抓包的作用
- **连接**：X25519 临时密钥交换 + ChaCha20-Poly1305 加密，每条连接都用新的临时密钥（**前向保密**：以后就算密钥泄露，也解不开以前的消息）；双方用身份密钥签名互相确认身份；每帧都填充到 256 字节的倍数，隐藏真实长度
- **防扫描**：建立连接的第一个包必须带"共同空间"的证明，否则一个字节都不回。隐身状态下，没有共同暗号的人连你的端口什么也得不到
- **群成员证明**：谁和你在同一个暗号群，是用只有群成员才能算出的证明来确认的，其他人看到的只是随机数
- **群消息**：在点对点加密之外，再用群密钥加密一层
- **图片**：发送前重新编码（去掉 EXIF 里的 GPS 位置、拍摄设备等信息），大图拆成分片加密传输；接收方先检查格式和尺寸再解码，防止恶意图片撑爆内存
- **文件**：发送方只发一个「文件邀请」，对方确认后才逐块加密传输（原始字节，不浪费流量），传完用 SHA-256 校验；只有能看到这条消息的人（私聊对象 / 同群成员 / 大厅成员）才能下载；文件名会去掉路径和非法字符，可执行文件会提示风险
- **本机保存的内容**：不写日志；提示音由程序实时合成，没有声音文件。会保存到硬盘的只有下面这些，都在 `%LOCALAPPDATA%\MiYu` 里，全部用 Windows 自带的 DPAPI 加密（绑定当前 Windows 账号，换电脑或换账号都解不开），看起来只是几个打不开的文件：
  - `p.bin` 账户（开了「记住登录」才有）：身份私钥、昵称、暗号群的**群密钥**（不保存暗号本身）、设置、宠物成长、已验证的人、还没被下载完的文件邀请
  - `f.bin` 我的收藏（开了「记住登录」就有）
  - `m.db` 聊天记录数据库（开了「保存聊天记录」才有，默认关闭）：每条消息用 ChaCha20-Poly1305 单独加密，会话名和消息编号只存 HMAC 摘要，文件里看不到任何明文；数据库密钥是随机生成的，保存在 `p.bin` 里（所以同样受 DPAPI 和启动密码保护）。阅后即焚、已撤回的消息不保存。1.x 的旧记录文件 `h.bin` 升级后改名成 `h.bin.v1bak` 备份
  - `cache\` 表情包
  - `out\` 发送文件夹时临时打包的 zip（一周后自动清掉）
  - 设了启动密码时，`p.bin` 里面再用密码派生的密钥（scrypt + ChaCha20-Poly1305）加密一层；数据库密钥在 `p.bin` 里，所以没有密码也打不开聊天记录
  - 「注销账户」会先用随机数据覆盖再删除（SSD 上不能保证物理擦除，但文件本来就是加密的）
- **文件传输**：每块 512KB，加大了 TCP 收发缓冲并关闭 Nagle，速度只受网速限制；断点续传时双方都会把已传部分重新算进 SHA-256，最后整体校验，中途被篡改或文件被改动都会被发现

### 做不到的事（请务必知道）

- 谁是坏鸭由房主的电脑当裁判，房主的软件知道所有人的身份（界面上不显示），改过的客户端理论上能偷看，所以这个游戏只图好玩、不计入任何排行榜；房主掉线这局就结束，不能换房主接着玩
- 谁是卧底同样由房主的电脑当裁判，房主的软件知道每个人的词；只图好玩
- 边下边看时播放器从本机的小服务器读视频，只有自己这台电脑能连（127.0.0.1 + 随机口令）；本机上别的程序要是拿到了地址也能读这个视频，看完关掉播放器地址就作废
- 宠物排行榜的名片能保证是本人发的、没被别人改过，但经验是在本人电脑上涨的，改过的软件可以虚报（只能标 ⚠，挡不住）
- 五子棋排行榜能保证每一局真的是这两个身份下的、结果没被改过，但如果同一个人开好几个身份（好几台电脑）自己和自己下，还是能在上限内刷分（每一对身份 24 小时最多 15 分）
- 公开大厅的内容，任何装了这个软件的人都能看到 → 敏感内容请用私聊或暗号群
- 网管能看到你的电脑在和哪些 IP 通信、流量大小（看不到内容）
- 电脑本身被装了监控 / 录屏软件，任何加密都防不住
- 阅后即焚只是从界面删除，防不了对方截图、拍照
- 暗号太简单（短、常用词）可能被抓包的人离线猜出来 → 建议 12 个字以上，或几个不相关的词拼起来
- 想把某人踢出暗号群，只能所有人换一个新暗号
- exe 是单文件版，运行时会解压到系统临时目录，正常退出后自动删除

## 四、常见问题

**看不到对方？**
1. 确认两台电脑连的是同一个路由器 / 同一个网段（IP 前三段一样，比如都是 192.168.1.x）
2. 确认双方都允许了防火墙（见上面）
3. 如果在一个空间里：都在大厅，或者用的是同一个暗号
4. 有些路由器 / 公司 Wi-Fi 开了「AP 隔离」，广播过不去 → 用 ⚙ →「手动添加对方 IP」

**同一台电脑想开两个测试？** 可以，直接打开两次就行（第二个会自动换端口）。

**端口**：UDP 47820（发现广播，所有人必须一样）、TCP 47821（连接，被占用会自动换）。

**杀毒软件报毒？** PyInstaller 打包的单文件 exe 偶尔会被误报。可以改用 `run.bat` 直接运行源码。

## 发布新版（局域网自动更新）

1. 改 `miyu/version.py` 里的版本号（比如 `2.0.0` → `2.0.1`）。版本号不变的话，别人的软件不会认为有更新。
2. 在 `miyu/changelog.py` 最上面加一条，写这一版更新了什么（自动测试会检查版本号和更新记录对得上）。别人收到新版本时、安装前、更新后第一次打开都能看到这些内容。
3. 双击 `build.bat`。它会自动给 `dist\MiYu.exe` 签名，并检查签完还能正常启动。
4. 自己换上新的 exe。局域网里其他人（已经在用带自动更新的版本）会自动发现并更新。

**发布私钥** 在 `%USERPROFILE%\.miyu_release\key.bin`，第一次打包时自动生成：

- 请备份这个文件。换电脑打包时把它拷到新电脑的同一位置。
- 丢了的话，新打包的版本别人的软件不会接受，只能再手动发一次 exe 给大家。
- 不要发给别人：拿到它的人可以发布所有人都会接受的「更新」。
- 一起用的人必须都用 **你打包的 exe**。别人自己从源码打包的版本用的是另一把钥匙，互相不能更新（聊天不受影响）。
